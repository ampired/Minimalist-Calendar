# Minimalist Calendar

I built this because I was tired of calendar apps full of menus, notifications, and features I never actually use. This is meant to be the simplest possible version of a calendar.

It's a single HTML file with no frameworks, no build steps, and no accounts. 

### How it works
* Click on any day to write a note and assign a color to it.
* Switch between light and dark mode with the button in the bottom-right corner.
* Everything is saved locally in your browser's `localStorage`.

To use it, just download `Calendar.html` and open it in your browser.
